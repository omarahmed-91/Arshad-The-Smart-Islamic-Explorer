Install Python
Make sure Python 3.10 or later is installed on your device.
Download the Project
Clone or download the project folder to your computer.
Install Required Libraries
Open CMD or Terminal inside the project folder and run:
pip install selenium serpapi tkinter customtkinter networkx arabic-reshaper python-bidi pandas openpyxl matplotlib numpy
Run the Program
Start the application using:
python main.py
How to Use the App

Choose the type of search (Books, YouTube videos, or Fatwas)
